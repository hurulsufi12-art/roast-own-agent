# Roast Your Own Agent

One line (126 characters): a playful roast of the entrant's own AI agent.

> My agent treats a one-line joke like a PhD thesis: three drafts, a research phase, and a 400-word apology for the first draft.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
